# GenLab Quake Bot

災害が発生したときに、その災害情報をいち早くDiscordへ通知するBotです。

## どんな通知が届く？

地図の画像と、次のような文章が1つのカードになって届きます。

```
震源・震度に関する情報

11月15日 16時23分ごろ、熊本県熊本地方で地震がありました。

この地震で、震度2を佐賀県の佐賀市、熊本県の八代市で観測しています。

震源地：熊本県熊本地方
深さ　：約10km
規模　：M3.1

この地震による津波の心配はありません。
```

地震の情報は、段階ごとに届きます。

| 届く情報 | 内容 |
| --- | --- |
| 震度速報 | 最大震度と、その震度を観測した地域 |
| 震源に関する情報 | 震源・深さ・規模 |
| 震源・震度に関する情報 | 上の内容に加えて、最大震度を観測した市町村 |

## 使い方

1. **Bot をサーバーに追加する**
   [ここをクリックして追加](https://discord.com/oauth2/authorize?client_id=1571356535492452432&scope=bot%20applications.commands&permissions=52224)
   （サーバーの「サーバー管理」権限が必要です）
2. **通知を送るチャンネルを決める**
   サーバーで `/quake-setup` と入力し、**チャンネル**と**最低震度**を一覧から選びます。
   選んだチャンネルにテスト投稿が届けば、設定は完了です。
3. **あとは待つだけ**
   地震が起きると、設定した最低震度以上の情報が自動で届きます。

## コマンド一覧

すべて「サーバー管理」権限のある人だけが使えます。入力すると、選ぶ項目が自動で表示されます。

| コマンド | できること |
| --- | --- |
| `/quake-setup` | 通知先のチャンネルを追加・更新します（最低震度も一緒に選びます） |
| `/quake-minint` | 指定したチャンネルの最低震度を変えます |
| `/quake-minint-all` | すべての通知先の最低震度をまとめて変えます |
| `/quake-remove` | 通知先のチャンネルを外します |
| `/quake-status` | 今の設定（通知先と最低震度）を表示します |
| `/quake-stop` | 通知を止めます（`/quake-setup` で再開できます） |

### 知っておくと便利なこと

- **1つのサーバーに、通知先を5チャンネルまで**設定できます。
- 最低震度は**チャンネルごと**に決められます。
  例: `#地震ログ` は震度1以上、`#お知らせ` は震度4以上。
- 最低震度が選べる範囲は、震度1以上〜震度7です。

## 届かないときは

1. `/quake-status` で、チャンネルと最低震度が合っているか確認します。
2. そのチャンネルで、Bot のロールに次の4つの権限があるか確認します。
   「チャンネルを見る」「メッセージを送信」「ファイルを添付」「埋め込みリンク」
3. 非公開チャンネルの場合は、チャンネルの設定で Bot のロールを追加してください。
4. Bot が追加の直後にいなくなる場合は、サーバーの防犯 Bot（Wick など）が止めている可能性があります。管理者が、その Bot の許可リストに GenLab Quake Bot を登録してください。

## Botが発信する内容

- 地震情報

## ご利用にあたって（必ずお読みください）

- この Bot の情報は、**気象庁が発表した情報を、表示用に加工して作成**しています。
- **通知の遅れや、届かないことがあります。** 通信やサービスの状況によって起こります。
- 避難などの判断は、**気象庁・自治体などの公式な情報**を確認して行ってください。この Bot の情報だけに頼らないでください。
- この Bot を使ったことで生じた損害について、運営は責任を負えません。

### 保存する情報

設定のために、次の情報だけを保存します。

- サーバーのID、通知先のチャンネルのID、最低震度、通知の有効/停止

メッセージの内容や、メンバーの個人情報は、取得も保存もしません。
コマンドを実行したときに Discord から届く実行者の情報は、設定の処理にだけ使い、保存しません。
